# Comece aqui

1. **Não use o ZIP anterior.** Este é o projeto novo, focado somente em investigações.
2. Extraia este ZIP.
3. No GitHub Web, envie tudo que está no mesmo nível do `package.json`.
4. Importe o repositório na Vercel.
5. Cadastre `ADMIN_USER` e `ADMIN_PASSWORD` na Vercel.
6. O site abrirá com três casos claramente marcados como demonstração.
7. Para salvar investigações e receber pistas, crie o Supabase e execute `supabase/schema.sql`.
8. Antes de colocar um caso real no ar, leia `METODOLOGIA_EDITORIAL.md`.

Acesse `/admin` para a redação e `/investigacoes` para o arquivo público.
